# PBFF শর্ট URL জেনারেটর

**PBFF Short URL Generator** ব্যবহার করে সহজেই বড় URL ছোট করুন, QR কোড তৈরি করুন এবং শর্ট লিংকের ক্লিক সংখ্যা দেখুন।

## 🌐 ওয়েবসাইট ভিজিট করুন

👉 **[PBFF Short URL Generator খুলুন](https://premiumbanglafont-netizen.github.io/PBFF-Short-URL/)**

উপরের লিংকে ক্লিক করলেই সরাসরি আমাদের ওয়েবসাইটে যেতে পারবেন।

## ✨ প্রধান সুবিধা

- লম্বা URL থেকে ছোট লিংক তৈরি
- নিজের পছন্দমতো Custom Alias যোগ করার সুবিধা
- শর্ট লিংকের QR Code তৈরি ও ডাউনলোড
- লিংক Copy ও Share করা
- লিংকে কতবার ক্লিক হয়েছে তা দেখা
- সাম্প্রতিক তৈরি করা পাবলিক লিংক দেখা
- লিংকের তথ্য CSV ফাইলে Export করা

## 📝 কীভাবে ব্যবহার করবেন

১. [PBFF Short URL Generator ওয়েবসাইটে যান](https://pbff.pbff.workers.dev/KbCj6se)।

২. **আপনার মূল URL** বক্সে যে লিংকটি ছোট করতে চান, সেটি পেস্ট করুন।

৩. চাইলে **Custom Alias** বক্সে নিজের পছন্দের নাম লিখুন। এটি ঐচ্ছিক।

৪. **Shorten URL** বাটনে ক্লিক করুন।

৫. তৈরি হওয়া শর্ট লিংক Copy করুন অথবা QR Code ডাউনলোড করুন।
